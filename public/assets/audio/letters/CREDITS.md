# صدای نشانه‌ها
lNN.mp3 = صدای ضبط‌شدهٔ نشانهٔ درس NN (ترتیب curriculum.ts)، ضبط اختصاصی برای «دهکده الفبا».
بلندی صداها یکسان‌سازی و سکوت ابتدا/انتها کوتاه شده است (تک‌کاناله، ۹۶kbps).
- l26 (ـو «اُ») = همان l16 (اُ)
- l30 (خوا) و l31 (تشدید) فعلاً صدا ندارند و بی‌صدا هستند.
- همهٔ صداها دو پرده زیرتر و کمی کودکانه شده‌اند (rubberband، pitch=1.1225، formant=shifted).
